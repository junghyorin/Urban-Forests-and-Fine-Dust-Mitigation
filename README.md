# 2025 데이터사이언스 팀프로젝트  
## 도시숲 공간정보 기반 AI 미세먼지(PM10) 예측 모델

---

## 📌 과제 개요
도시숲의 **위치, 면적, 거리 등 공간 정보**를 활용한  
AI 기반 **미세먼지(PM10) 예측 모델**을 개발한다.  

이를 통해 도시숲에 의한 **미세먼지 저감 효과를 정량적으로 분석**하고,  
단순 면적 확대를 넘어 **저감 효과를 극대화할 수 있는 도시숲의 최적 입지와 규모**를  
과학적으로 도출하는 것을 목표로 한다.

---

## 📊 활용 데이터

### 1️⃣ 도시숲 공간 정보
- **출처**: 서울시 공공데이터 (서울특별시청)
- **형식**: CSV / GeoJSON
- **내용**: 도시숲명, 위도, 경도, 면적 등
- **수집 방식**: 웹 크롤링을 통한 자체 데이터 구축

### 2️⃣ 미세먼지 관측 데이터
- **출처**: 서울시 대기환경정보 API
- **형식**: CSV (시간 단위 시계열)
- **내용**: PM10 농도
- **시간 해상도**: 1시간
- **수집 방식**: API 호출

### 3️⃣ 미세먼지 관측소 위치 정보
- **출처**: 서울시 대기환경정보
- **형식**: Text
- **내용**: 서울시 구별 미세먼지 관측소 위도, 경도

### 4️⃣ 종관 기상 관측 데이터 (ASOS)
- **출처**: 기상청 허브 API
- **형식**: CSV (시간 단위 시계열)
- **내용**:
  - 풍향
  - 풍속
  - 지면기압
  - 기온
  - 습도
  - 강수량
- **시간 해상도**: 1시간
- **수집 방식**: API 호출

## 🔍 분석 내용

### 1️⃣ 전처리 및 탐색적 데이터 분석 (EDA)

#### 1-1) 위·경도 기반 격자 변환 및 좌표계 통일
- 도시숲 중심 좌표 및 자치구별 측정소 좌표를  
  서울시 면적 기준 **픽셀 좌표**로 변환
- 서울특별시 위·경도 경계 기준
  - 위도: `[37.413, 37.715]`
  - 경도: `[126.734, 127.269]`

#### 1-2) 도시숲과 측정소 간 공간 관계 계산
- 각 측정소 기준 **가장 가까운 3개 도시숲** 선택
- 거리 계산
  - 픽셀 간 **유클리드 거리**
- 방향 정보 계산
  - 픽셀 간 **sin, cos 값** 활용
- 거리 감쇠 함수 적용
  - 거리 기반 가중치 계산
  - 가중 평균을 통해 **도시숲 면적 + 거리 영향 반영**

#### 1-3) 기상 데이터 및 미세먼지 데이터 결합
- 대상 기간: **2024년**
- 샘플링 방식
  - 주 4일 (평일 3일, 주말 1일)
  - 1시간 간격
- 결합 방식
  - 기상 데이터: 서울시 전역 공통 적용
  - 미세먼지 데이터: 자치구별 관측소 데이터 사용

#### 1-4) 날짜 및 시간 파생 변수 생성
- 타임스탬프 분리
  - 월
  - 요일
- 계절 변수 생성
  - 봄: 3, 4, 5월
  - 여름: 6, 7, 8월
  - 가을: 9, 10, 11월
  - 겨울: 12, 1, 2월
